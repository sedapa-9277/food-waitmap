⏱ 맛집 대기지도

전국 맛집의 예상 대기시간을 지도에서 확인하고, 로그인 없이 지금 기다리는 시간을 공유하세요.

지도에서 대기시간 보기OpenStreetMap 식당 + 실시간 대기시간 공유 퍼블리싱 시안가상 데이터로 보는 UI 시안

맛집 대기지도란?

맛집 대기지도는 식당에 도착하기 전에 예상 대기시간을 알려 주는 무료 지도 서비스입니다. 현장에 있는 사용자가 지금 기다리는 시간을 입력하면, 여러 사람의 입력을 모아 평균 대기시간을 보여 줍니다.

한 사람의 입력만으로는 평균을 표시하지 않고, 각 입력은 30분 뒤 자동으로 빠지기 때문에 오래되거나 한쪽으로 치우친 정보가 남지 않습니다.

이용 방법

  1. 지도 탐색: 내 위치나 원하는 지역으로 지도를 옮깁니다. 지도 중심에서 가까운 식당 최대 20곳이 표시됩니다.
  2. 식당 선택: 마커나 목록에서 식당을 누르면 식당명, 주요 메뉴, 예상 대기시간, 참여 인원, 최종 업데이트 시각이 나옵니다.
  3. 대기시간 입력: 지금 기다리는 시간을 5분 단위로 입력합니다. 로그인은 필요 없습니다.
  4. 평균 확인: 서로 다른 사용자 2명 이상이 입력하면 평균 대기시간이 표시됩니다.

대기시간 집계 기준

평균 표시 조건서로 다른 사용자 2명 이상의 유효한 입력
계산 방식유효한 입력의 평균을 1분 단위로 반올림 (예: 20분 + 40분 → 30분)
입력 유효 시간입력마다 등록 시각부터 30분 (서버 시각 기준)
입력 범위0분 ~ 300분, 5분 단위
중복 입력같은 사용자가 같은 식당에 다시 입력하면 기존 값을 갱신
표시 상태정보 수집 중(0명) · 입력 참여 중(1명) · 평균 대기시간(2명 이상)

자주 묻는 질문

맛집 대기지도는 어떤 서비스인가요?

전국 맛집의 예상 대기시간을 지도에서 확인하고, 현장에 있는 사용자가 직접 대기시간을 입력해 공유하는 무료 웹 서비스입니다. 식당에 도착하기 전에 얼마나 기다려야 하는지 미리 알 수 있습니다.

회원가입이나 로그인이 필요한가요?

필요 없습니다. 누구나 바로 지도를 보고 대기시간을 입력할 수 있습니다. 중복 입력은 브라우저별 익명 ID와 요청 제한으로 막습니다.

대기시간은 어떻게 계산하나요?

현재 유효한 입력의 평균을 1분 단위로 반올림해 보여 줍니다. 한 사람의 입력만으로는 평균을 표시하지 않고, 서로 다른 사용자 2명 이상이 입력했을 때만 표시합니다. 예를 들어 20분과 40분이 입력되면 평균 30분으로 표시됩니다.

대기시간 정보는 얼마나 최신인가요?

각 입력은 등록 시각부터 30분 동안만 집계에 반영되고 이후 자동으로 빠집니다. 만료 판정은 서버 시각 기준이며, 화면에는 최종 업데이트 시각과 참여 인원이 함께 표시됩니다.

대기시간은 어떻게 입력하나요?

지도에서 식당을 선택한 뒤 0분부터 300분까지 5분 단위로 입력하거나 빠른 선택 버튼을 누르면 됩니다. 같은 식당에 다시 입력하면 기존 값이 새 값으로 갱신됩니다.

'정보 수집 중'은 무슨 뜻인가요?

최근 30분 안에 유효한 입력이 없거나 1명만 입력해 아직 평균을 낼 수 없는 상태입니다. 다른 사용자가 입력해 2명 이상이 되면 평균 대기시간이 표시됩니다.

지도·식당 정보: OpenStreetMap 기여자. 대기시간은 사용자 입력을 집계한 참고용 정보이며 실제와 다를 수 있습니다.
